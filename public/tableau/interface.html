🧭 Interface Basics

Tableau has one core mechanic: drag a field onto a shelf. Everything else is variation. Learn what each shelf does and what the blue/green colour coding means, and the rest of the tool stops feeling arbitrary.

🔤 Field types and the icons that announce them

Before anything else, Tableau assigns every column a data type, and it shows you which one with a small icon in the Data pane. The type is decided when you connect and it constrains everything afterwards — which functions accept the field, whether it can go on a date axis, whether it can be summed. Getting one wrong is the cause of a surprising share of "Tableau won't let me" moments.

What the type decides

  • Whether it lands in Dimensions or Measures. Numbers go to Measures, everything else to Dimensions — which is why Row ID and Postal Code arrive as things to be summed.
  • Which functions accept it. DATEDIFF refuses a string that looks like a date; LEFT refuses a number.
  • Whether a date hierarchy exists. A date read as text gets no Year → Quarter → Month drill-down, and sorts "April" before "January".
  • Whether it can be mapped. A geographic role can only sit on a string, so a postcode read as a number has to be converted first.

Change it by clicking the icon — on the Data Source page for a permanent fix, or in the Data pane via ▾ → Change Data Type.

Fix the type at the source, not in a calculation

Wrapping a text date in DATE([Order Date]) works, but you now have two fields, and everyone else opening the workbook will use the wrong one. Changing the type on the Data Source page fixes it once, everywhere, forever — see Connecting Data.

🔵🟢 Dimensions vs Measures

Every field is one or the other, and which one it is decides what dragging it does: dimensions carve the sheet into slots, measures put numbers in those slots. Tableau colour-codes the two so you can tell at a glance.

Dimensions — blue

Categorical. Answers what or who.

  • Region, Category, Customer Name
  • Dates (usable either way)
  • IDs, codes, labels

They slice the data — adding one creates more rows or columns.

Measures — green

Numeric and aggregatable. Answers how much.

  • Sales, Profit, Quantity, Discount
  • Automatically summed or averaged

They fill the data — adding one gives every slice a number.

Watch it happen: slice, then fill

Start with an empty sheet and add one field at a time. A dimension carves the sheet into slots; a measure puts a number in each one.

The one-sentence rule

Dimensions slice; measures fill. "Sales by Region" is one measure sliced by one dimension. Nearly every chart you will ever build is some arrangement of that sentence.

Watch out for numeric IDs

Tableau sees any numeric column as a measure, including things like Postal Code and Row ID. Summing postcodes is meaningless. Drag those fields up into the Dimensions area to fix it once, permanently.

🔀 Discrete vs Continuous — the second colour rule

Blue means discrete; green means continuous. This is a second, independent distinction — dimension/measure says what kind of field it is, discrete/continuous says how Tableau draws it. Most dimensions happen to be discrete and most measures continuous, which is why the two look like one rule at first, but either can be switched: a date dimension can be green and continuous (one timeline), and a measure can be blue and discrete (a label rather than an axis). Right-click a pill and you can flip it.

Discrete — distinct values

  • Creates headers — separate labelled panes
  • Finite, separable values
  • Can be sorted and grouped

Continuous — an unbroken range

  • Creates an axis — a continuous scale
  • Any value in between is meaningful
  • Used for lines and positions

The same field, two colours, two charts

Both of these are MONTH(Order Date) over the same four years of data. The only difference is which one you picked from the right-click menu.

MONTH blue · discrete
Twelve buckets. All four years pooled into each month. Answers: is there seasonality?
MONTH green · continuous
One timeline running straight through. Answers: are we growing?

Right-click any date pill and you get two lists of the same words. The top list is blue and discrete; the bottom is green and continuous. Picking from the wrong one is why a line chart sometimes comes out as disconnected chunks.

Where it bites: dates

Right-click a date pill and you get two lists. Picking Year from the top (blue, discrete) gives you separate columns per year — good for comparing 2016 against 2017. Picking Year from the bottom (green, continuous) gives you one unbroken time axis — good for showing a trend. Same field, same word, completely different chart. When a line chart mysteriously splits into disconnected chunks, this is why. The full date menu is broken down further down this page.

The two switches are independent — all four combinations exist

Dimension/measure and discrete/continuous are separate properties. Most fields sit in the two obvious corners, which is why they look like one rule — but the other two corners are real, useful, and the source of a lot of confusion when you meet them by accident.

The same field can occupy any of these four boxes. Moving it left or right changes how it's drawn; moving it up or down changes whether it's aggregated. They are two independent switches, and each fixes a different problem.

Discrete — blueContinuous — green
Dimension
not aggregated		 The normal case. Region, Category, a blue YEAR. Makes headers; sortable; groupable. A green date, or a numeric dimension on an axis. One continuous timeline; or plotting a rating 1–10 as a real scale without summing it.
Measure
aggregated		 A discrete aggregate. Blue SUM(Sales) makes one header per distinct total. Used in text tables, and to sort or label by a number without giving it an axis. The normal case. Green SUM(Sales). Makes an axis; the thing bars stretch along.

The practical consequence: "make it a dimension" and "make it discrete" are different instructions and fix different problems. Converting Postal Code to a dimension stops Tableau summing it. Converting it to discrete is what lets you tick individual codes in a filter. Fields like this usually need both.

🚦 What blue and green actually gate

Discrete versus continuous is not a formatting preference. It decides which menus exist, which dialogs open, and which features are greyed out — and Tableau almost never explains why something isn't available. This table is the answer to most of those moments.

Use the table backwards as a diagnostic

"Sort is greyed out." "There's no Edit Axis." "The trend line won't drop." "I can't get checkboxes." "Create Group is missing." Every one of those is the same fact arriving in a different disguise: the pill is the wrong colour for what you're trying to do. Check the pill before you go looking for a setting.

🔁 Converting a field — and the two places to do it

Both switches are reversible, and where you flip them decides how far the change reaches. This trips people up constantly: they convert a pill, build three more sheets, and find the change didn't come with them.

Right-click the pill in the view
  • Discrete ⇄ Continuous
  • Dimension ⇄ Measure
  • Measure → Sum / Average / Median / Count…

This view only. A new sheet starts from the field's default again — and so does a fresh drag onto the Filters shelf, which is why the filter dialog can stay stubbornly wrong.

→
Right-click the field in the Data pane
  • Convert to Discrete / Continuous
  • Convert to Dimension / Measure
  • Change Data Type
  • Default Properties → Aggregation, Number Format, Colour, Sort

The field's default, from now on. Every future drag, on every sheet, in every filter dialog. Almost always the one you want.

Default Properties is the setting people never find

Right-click a field → Default Properties and you can fix, once and permanently: its aggregation (so Discount defaults to Average rather than Sum), its number format (so a margin is a percentage everywhere without formatting each sheet), its colour (so Region members keep the same colours across a whole dashboard), and its sort order. Ten seconds here removes a formatting job from every sheet you build afterwards.

Not every field can be converted

A string can be made continuous only by first converting it to a number — text has no scale. A measure can be made discrete freely, but the result is aggregated first, so blue SUM(Sales) is one header per total, not per row. And a date is the flexible one: it can be discrete or continuous, dimension or measure, in any combination.

📅 Dates in depth — one field, a dozen pills

A date is the only field that offers you a whole menu when you right-click it, and the menu has two halves that use the same words. Knowing which half you are in is most of what there is to know about dates in Tableau.

The menu really does list the same five words twice. The top block extracts a component; the bottom block rounds the date down and keeps it a date. The right-hand column of the menu previews what one date — 8 May 2015 — becomes in each case.

The mistake that quadruples a number

Blue Month and blue Month / Year look almost identical in the menu and produce very different charts. With four years of data, a "monthly sales" chart built on the date part shows twelve bars each containing four years of sales — roughly four times the number anyone expects, and nothing on the chart says so. If a monthly chart has exactly twelve bars across a multi-year dataset, you are on the wrong half of the menu.

Drilling, and the date hierarchy

A date pill arrives with a + on it. Clicking it drills Year → Quarter → Month → Day, adding a pill each time and nesting the headers. That built-in hierarchy is why a date behaves unlike every other field, and why an Exact Date pill has no + — there is nothing below it.

  • Drilling adds pills — Year then Quarter gives 4 × 4 nested headers, not 16 separate ones
  • Green date pills don't nest — a continuous axis can only show one granularity at a time
  • The classic combination: green Month on Columns for a continuous trend, blue Year on Rows for one row per year — small multiples that compare the same twelve months across four years
  • Show Missing Values on a blue date pill draws the empty periods. Without it, a month with no orders simply isn't there and a line chart joins straight across the gap as if nothing happened
Fiscal years live in Default Properties

If your year doesn't start in January: right-click the date field → Default Properties → Fiscal Year Start. Every Year, Quarter and week calculation on that field then uses it. Doing this with calculated fields instead is a well-trodden route to a workbook nobody can maintain.

🎯 The Marks card targets, side by side

Every target does something different to the same chart. Here is one scatter of Sales vs Profit, with Category or Quantity dropped on each target in turn.

Nothing on Marks
One dot — the grand total of all 9,994 rows. Two measures alone give you one mark.
Sub-Cat on Detail
Splits into 17 dots — one per sub-category. Detail adds granularity and changes nothing else. This is what makes it a scatter plot.
Category on Color
Same dots, now coloured by group, and a legend appears beside the chart.
Quantity on Size
Dot area now carries a third number. Three variables in one chart.
Sub-Cat on Label
Prints text on the marks. Often lets you delete the legend entirely.
Category on Shape
Different symbols per group. A weak channel — four or five max.
Detail is the odd one out — and the one to understand first

Color, Size, Label and Shape all change how marks look. Detail changes how many marks there are. If a chart shows one mark when you expected many, something needs to go on Detail. If it shows too many, something on Detail should come off.

🏗️ Building your first view

  1. Drag Category to Rows

    Three row headers appear — Furniture, Office Supplies, Technology. No numbers yet, because you've sliced without filling.

  2. Drag Sales to Columns

    Tableau aggregates to SUM(Sales) automatically and draws horizontal bars. You have a chart.

  3. Sort it

    Hover the Sales axis and click the descending sort icon. The biggest category moves to the top, so the ranking is readable from the shape alone instead of by comparing numbers.

  4. Add a second dimension to Color

    Drag Region onto Color. The bars split into stacked segments — one chart now carries two dimensions.

  5. Swap the axes

    Press Ctrl W to flip rows and columns. Vertical columns instead of horizontal bars — same data, different emphasis.

The fastest way to learn: double-click everything

Double-clicking a field drops it where Tableau thinks it belongs. Double-click Sales, then Category, then Region, and watch what happens at each step. Tableau's guesses follow the same rules you're learning — measures go to an axis, dimensions go to a shelf as headers — so watching where each field lands teaches you the shelves faster than planning every drag yourself.

🧠 Key intuitions

  • Dimensions slice, measures fill — the sentence that explains most charts
  • Blue is discrete, green is continuous — headers vs axes
  • Dimension/measure and discrete/continuous are two separate switches — all four combinations exist
  • Blue/green gates the menus — sorting, Edit Axis, groups, trend lines, filter dialogs
  • Convert in the Data pane, not on the pill, unless you mean this view only
  • Default Properties fixes aggregation, format, colour and sort once for every future sheet
  • Rows = Y, Columns = X — counterintuitive, worth memorising
  • Detail adds granularity without appearance
  • Dates come in blue and green versions — the cause of most surprised line charts
  • Double-click to explore — watching Tableau's guesses teaches the shelves
  • Right-click everything — nearly every option lives in a context menu
  • Numeric IDs aren't measures — drag them into Dimensions

🎯 Practice exercises

  1. Build a bar chart of Sales by Region and sort it descending
  2. Drag Segment to Color and describe what changed
  3. Press Ctrl W to swap the axes
  4. Drag Sales to Label so values print on the bars
  5. Put Category on Rows and Region on Columns — what kind of view is that?
  6. Drag Order Date to Columns and note that Tableau defaults to YEAR
  7. Right-click the date pill and switch between the blue Month and the green Month; explain the difference in one sentence
  8. Now compare blue Month with blue Month / Year — count the bars in each and say why they differ
  9. Try to sort a continuous axis, add a trend line to a discrete header, and Create Group on a green measure. Note the exact wording Tableau uses each time it refuses
  10. Set Default Properties → Aggregation → Average on Discount and confirm new sheets pick it up
  11. Double-click Profit on an empty sheet and see what Tableau builds unprompted
  12. Build a scatter of Sales vs Profit, then drag Sub-Category to Detail — watch one dot become seventeen
  13. Click through Show Me with Category and Sales selected; note which options are greyed out and why
  14. Find Postal Code in Measures and move it to Dimensions
  15. Clear the sheet and rebuild Sales by Region from memory, without looking back
🏆 Challenge: one dataset, six views, ten minutes

Give yourself ten minutes and build six different views of Superstore — no planning, no perfectionism. Then look at them together and pick the one that tells you something you didn't already know. Five of the six being useless is the expected result: the aim is to find out which questions the data answers well, and that is cheaper to discover by building six charts than by reasoning about it in advance.
